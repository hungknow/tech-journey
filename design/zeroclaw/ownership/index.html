    ZeroClaw: Ownership, Borrowing, and Per-Module Patterns

    Focus: common ownership/borrow patterns (with Rust template code) and, per module, pseudo Rust that illustrates who owns or borrows what. Each line at most 120 characters. No tables.

    Comment convention in pseudo-code - // BORROW: caller does not take ownership; use for the duration of the call or expression only. - // OWNED: the value is owned (moved or created here); caller/struct is the single owner. - // SHARED: Arc (or clone of Arc); multiple owners, no move of the inner value. - // TRANSFER: ownership is moved from one place to another (e.g. into a Vec, or via send()).

    Common methods to manage ownership and borrow

    These patterns appear across the workspace.

    Factory: take config by reference, return owned trait object

    // BORROW: config and path only read; not stored, not moved.
fn create_thing(config: &SomeConfig, path: &Path, api_key: Option<&str>)
    -> anyhow::Result<Box<dyn SomeTrait>> {
    let inner = build_from(config)?;  // OWNED: inner is owned locally
    Ok(Box::new(inner))              // TRANSFER: inner moved into Box; Box returned to caller
}

    Exclusive ownership: one owner holds a Box

    struct Owner {
    implementation: Box<dyn SomeTrait>,  // OWNED: Owner is the single owner of the trait object
}
// When Owner is dropped, the Box (and the dyn SomeTrait) is dropped.

    Shared ownership: many tasks/handlers share via Arc

    struct SharedContext {
    provider: Arc<dyn Provider>,   // SHARED: ref-counted; clone = another pointer, same heap value
    tools: Arc<Vec<Box<dyn Tool>>>,
}
// In a worker task:
let ctx = Arc::clone(&context);   // SHARED: clone Arc, context still owns original; ctx shares same data
spawn(async move { use ctx.provider... });

    Collection owning a list of trait objects

    let mut list: Vec<Box<dyn Tool>> = vec![];   // OWNED: list owns the Vec
let security = Arc::new(SecurityPolicy::default());
list.push(Box::new(ShellTool::new(
    security.clone(),   // SHARED: clone Arc so ShellTool shares the same policy
    runtime,
)));                    // TRANSFER: Box moved into list; list now owns that tool

    Wrapper owning inner trait objects (no exposure)

    struct Wrapper {
    inners: Vec<(String, Box<dyn Provider>)>,  // OWNED: Wrapper owns the Vec and every Box inside
}
impl SomeTrait for Wrapper {
    fn do_it(&self) {
        // BORROW: self borrowed; get ref to one inner, call it; no move out of self.providers
        let (_, ref box_provider) = self.inners[idx];
        box_provider.chat(...).await;
    }
}

    Shared mutable state: Arc>

    struct WithSharedState {
    storage: Arc<Mutex<Storage>>,  // SHARED: many can hold Arc; Mutex gives exclusive access when locked
}
fn update(&self) {
    let mut guard = self.storage.lock().unwrap();  // BORROW: guard mutably borrows the Storage
    guard.write(...);   // use guard; when guard is dropped, lock released
}

    Borrow for the duration of a call (no storage)

    fn process(config: &Config, messages: &[ChatMessage]) -> Result<()> {
    // BORROW: config and messages only used during this function
    let provider = create_provider(
        config.default_provider.as_deref(),  // BORROW: Option<&str>
        config.api_key.as_deref(),
    )?;   // OWNED: provider is owned by this function
    let request = ChatRequest { messages };  // BORROW: request holds &[ChatMessage], no copy
    provider.chat(request, model, temp).await?;  // BORROW: provider and request for duration of chat()
    Ok(())
}

    Optional owned value

    struct Container {
    optional_impl: Option<Box<dyn Memory>>,  // OWNED: if Some, Container owns the Box
}
// Config uses Option<TelegramConfig>: if Some, Config owns that TelegramConfig.

    Transfer ownership over channel

    let (tx, rx) = mpsc::channel::<Message>(100);
tx.send(message).await?;   // TRANSFER: message is moved into the channel; receiver will own it
let received = rx.recv().await;  // OWNED: received is Option<Message>; caller owns the Message

    Module: agent

    Orchestration: one Agent owns provider and tools; borrows memory and observer via Arc.

    struct Agent {
    provider: Box<dyn Provider>,      // OWNED: only this Agent holds this Box
    tools: Vec<Box<dyn Tool>>,       // OWNED: Agent owns the Vec and every Box in it
    memory: Arc<dyn Memory>,         // SHARED: clone for other code paths; not moved
    observer: Arc<dyn Observer>,      // SHARED: same
    tool_dispatcher: Box<dyn ToolDispatcher>,  // OWNED
    memory_loader: Box<dyn MemoryLoader>,     // OWNED
    history: Vec<ConversationMessage>,        // OWNED: we push/drain; mutable borrow in loop
    // ... config, model_name, workspace_dir, etc. (all OWNED)
}

// Builder: each field is Option<T>; build() moves each out into the new Agent.
impl AgentBuilder {
    pub fn build(self) -> Result<Agent> {
        let tools = self.tools.ok_or_else(|| anyhow!("tools required"))?;  // TRANSFER: move out
        let tool_specs = tools.iter().map(|t| t.spec()).collect();         // BORROW: tools for iteration
        Ok(Agent {
            provider: self.provider.unwrap(),   // TRANSFER: move out of Option
            tools,
            memory: self.memory.unwrap(),
            // ...
            history: Vec::new(),   // OWNED: new Vec
        })
    }
}

    Dispatcher and prompt: owned components, borrow inputs.

    trait ToolDispatcher {
    // BORROW: &self and response; return value OWNED by caller
    fn parse_response(&self, response: &ChatResponse) -> (String, Vec<ParsedToolCall>);
    fn format_results(&self, results: &[ToolExecutionResult]) -> ConversationMessage;
}

// When building prompt: ctx is borrowed; sections borrow &self; return String OWNED
fn build(&self, ctx: &PromptContext<'_>) -> Result<String>;

trait MemoryLoader {
    // BORROW: memory and user_message for the call; return String OWNED
    async fn load_context(&self, memory: &dyn Memory, user_message: &str) -> Result<String>;
}

    Example: one turn of the agent loop (simplified).

    fn process_message(&mut self, user_message: &str) -> Result<()> {
    // BORROW: self.memory for the duration of load_context
    let context = self.memory_loader.load_context(self.memory.as_ref(), user_message).await?;
    // BORROW: self.history to build messages for provider
    let messages = self.tool_dispatcher.to_provider_messages(&self.history);
    let request = ChatRequest { messages: &messages, tools: Some(&self.tool_specs) };
    // BORROW: self.provider and request for the duration of chat()
    let response = self.provider.chat(request, &self.model_name, self.temperature).await?;
    // BORROW: self.tool_dispatcher and response
    let (text, calls) = self.tool_dispatcher.parse_response(&response);
    for call in calls {
        let tool = self.tools.iter().find(|t| t.name() == call.name).map(|t| t.as_ref());
        let result = tool.unwrap().execute(call.arguments).await?;  // BORROW: tool and args
        // BORROW MUT: self.history to push new messages
        self.history.push(self.tool_dispatcher.format_results(&[result]));
    }
    Ok(())
}

    When used (borrow vs transfer)

    • AgentBuilder.build(self) — takes ownership of all Option fields; each .unwrap_or_else() or .ok_or_else() moves the value out of the builder into the new Agent. Builder is consumed.
    • turn(&mut self, user_message: &str) / run_single(&mut self, message: &str) — self is borrowed mutably for the whole call. provider, tools, observer, tool_dispatcher, memory_loader are borrowed via &self (read-only). history is borrowed mutably: trim_history(&mut self.history), .push(), .drain() modify it. memory is borrowed when calling memory_loader.load_context(self.memory.as_ref(), user_message) and when auto_saving; no move.
    • When calling provider.chat(...): request holds messages from to_provider_messages(&self.history) (temporary Vec); ChatRequest { messages: &messages, tools: Some(&self.tool_specs) } so provider borrows the slice for the duration of chat(). model_name and temperature are copied (Copy or clone) into the call.
    • Tool execution: self.tools.iter().find(...).map(|t| t.as_ref()) borrows the tools slice; tool.execute(args) borrows &self of the tool (and its Arc fields stay shared). Results are pushed onto self.history (history owns the new messages).
    • run_tool_call_loop(provider, &mut history, tools_registry, observer, ...) — caller passes provider as &dyn Provider, history as &mut Vec, tools as &[Box], observer as &dyn Observer. Borrows for the duration of the loop; nothing is moved in.

    Module: channels

    Channel runtime context is shared (Arc everywhere); no exclusive ownership inside context.

    struct ChannelRuntimeContext {
    channels_by_name: Arc<HashMap<String, Arc<dyn Channel>>>,  // SHARED: name -> channel
    provider: Arc<dyn Provider>,    // SHARED: same provider used by every worker
    memory: Arc<dyn Memory>,
    tools_registry: Arc<Vec<Box<dyn Tool>>>,
    observer: Arc<dyn Observer>,
    system_prompt: Arc<String>,
    model: Arc<String>,
    temperature: f64,
    auto_save_memory: bool,
}

// How context is built and used:
fn start_channels(config: Config) -> Result<()> {
    let provider = create_provider(...)?;           // OWNED: Box<dyn Provider>
    let provider = Arc::from(provider);             // TRANSFER: Box moved into Arc; Arc OWNED
    let ctx = ChannelRuntimeContext { provider, memory, tools_registry: Arc::new(tools), ... };
    let ctx = Arc::new(ctx);                        // SHARED: one Arc to the context
    let (tx, rx) = mpsc::channel(100);
    while let Some(msg) = rx.recv().await {         // OWNED: msg is owned by this task
        let worker_ctx = Arc::clone(&ctx);           // SHARED: clone Arc, same context
        spawn(async move {
            process_channel_message(worker_ctx, msg).await;  // BORROW ctx via Arc; msg MOVED in
        });
    }
}

    Channel trait: messages passed by reference for send; listen pushes into Sender (ownership transfer).

    trait Channel {
    async fn send(&self, message: &str, recipient: &str) -> Result<()>;
    // BORROW: &self, message, recipient; nothing stored by ref

    async fn listen(&self, tx: Sender<ChannelMessage>) -> Result<()>;
    // TRANSFER: tx is moved into listen. When channel does tx.send(msg).await, msg is MOVED to receiver.
}

    Inside process_channel_message (one worker).

    async fn process_channel_message(ctx: Arc<ChannelRuntimeContext>, msg: ChannelMessage) {
    // ctx: SHARED (Arc); msg: OWNED by this task (moved in)
    let memory_ctx = build_memory_context(ctx.memory.as_ref(), &msg.content).await;
    // BORROW: ctx.memory (via Arc), msg.content for the call

    ctx.memory.store(&key, &msg.content, category).await;
    // BORROW: ctx.memory, key, msg.content

    let channel = ctx.channels_by_name.get(&msg.channel).cloned();
    // BORROW: ctx and msg.channel; channel is Option<Arc<dyn Channel>> (SHARED clone)

    run_tool_call_loop(
        ctx.provider.as_ref(),      // BORROW: get &dyn Provider from Arc
        &mut history,               // BORROW MUT: local Vec, not ctx
        ctx.tools_registry.as_ref(),
        ctx.observer.as_ref(),
        ...
    ).await;

    channel.send(&response, &msg.sender).await;  // BORROW: response and msg.sender
}

    When used (borrow vs transfer)

    • start_channels(config) — config is moved into the function (or passed by ref and not stored). Created provider, memory, tools are wrapped in Arc; ownership of the Arc is stored in ChannelRuntimeContext. Context is then wrapped in Arc; no field is moved out.
    • run_message_dispatch_loop(rx, ctx, ...) — rx is moved into the loop (receiver owns the stream). ctx is Arc; each iteration does Arc::clone(&ctx) and spawn(move || process_channel_message( worker_ctx, msg)). So msg is moved into the task (ownership transfer from recv()); worker_ctx is a clone of the Arc (shared ref), not a move of the context.
    • process_channel_message(ctx, msg) — ctx is borrowed via Arc (so ctx.memory, ctx.provider, etc. are used by ref). msg is owned by the task (moved in). ctx.memory.store(..., &msg.content, ...) borrows msg.content for the call. build_memory_context(ctx.memory.as_ref(), &msg.content) borrows memory and msg.content. run_tool_ call_loop(ctx.provider.as_ref(), &mut history, ctx.tools_registry.as_ref(), ctx.observer.as_ref(), ...) borrows provider, the tools slice, and observer; history is local to the task (owned), passed &mut. channel lookup: ctx.channels_by_name.get(&msg.channel).cloned() returns Option> (clone of Arc); channel.send(&response, &msg.sender) borrows response and sender for the call.
    • Channel.send(&self, message: &str, recipient: &str) — channel is borrowed; message and recipient are borrowed for the call. listen(tx) — tx is moved into listen (ownership of the Sender); when the channel pushes ChannelMessage via tx.send(msg).await, ownership of msg is transferred to the receiver.
    // From src/channels/mod.rs
pub async fn start_channels(config: Config) -> Result<()> {
    let provider = Arc::from(providers::create_resilient_provider(...)?);  // TRANSFER: Box -> Arc
    let mem = Arc::from(memory::create_memory(...)?);
    let tools_registry = Arc::new(tools::all_tools_with_runtime(...));     // OWNED Vec moved into Arc
    let runtime_ctx = Arc::new(ChannelRuntimeContext {
        provider,
        memory: mem,
        tools_registry,
        // ...
    });   // OWNED context moved into Arc
    let (tx, rx) = tokio::sync::mpsc::channel(..);

async fn run_message_dispatch_loop(
    mut rx: tokio::sync::mpsc::Receiver<ChannelMessage>,
    ctx: Arc<ChannelRuntimeContext>,
    max_in_flight_messages: usize,
) {
    while let Some(msg) = rx.recv().await {   // OWNED: msg from recv()
        let worker_ctx = Arc::clone(&ctx);    // SHARED: clone Arc
        workers.spawn(async move {
            process_channel_message(worker_ctx, msg).await;  // BORROW ctx via Arc; TRANSFER msg into task
        });
    }
}

async fn process_channel_message(ctx: Arc<ChannelRuntimeContext>, msg: ChannelMessage) {
    let memory_context = build_memory_context(ctx.memory.as_ref(), &msg.content).await;  // BORROW
    ctx.memory.store(&autosave_key, &msg.content, category).await;                       // BORROW
    let target_channel = ctx.channels_by_name.get(&msg.channel).cloned();  // BORROW; Option<Arc<dyn Channel>>
    let mut history = vec![ChatMessage::system(...), ChatMessage::user(&enriched_message)];  // OWNED
    run_tool_call_loop(
        ctx.provider.as_ref(),
        &mut history,
        ctx.tools_registry.as_ref(),
        ctx.observer.as_ref(),
        ...
    ).await;   // BORROW provider, tools, observer; BORROW MUT history
    channel.send(&response, &msg.sender).await;  // BORROW response, msg.sender
}

    Factories return Box; wrappers own Vec of providers.

fn create_provider(name: &str, api_key: Option<&str>) -> Result<Box<dyn Provider>> {
    let client = match name {
        "openrouter" => Box::new(OpenRouterProvider::new(api_key)),
        // ...
    };
    Ok(client)  // TRANSFER: Box to caller
}

// Builds multiple Box<dyn Provider>, moves all into ReliableProvider
fn create_resilient_provider(name: &str, api_key: Option<&str>, reliability: &ReliabilityConfig)
    -> Result<Box<dyn Provider>>
{
    let mut providers = Vec::new();
    providers.push((name.into(), create_provider(name, api_key)?));  // TRANSFER: Box into Vec
    for fb in &reliability.fallback_providers {  // BORROW: slice
        providers.push((fb.clone(), create_provider(fb, api_key)?));
    }
    Ok(Box::new(ReliableProvider::new(providers)))  // TRANSFER: Vec moved into wrapper
}

    Wrapper types own inner providers; when used, they borrow from self.

    struct ReliableProvider {
    providers: Vec<(String, Box<dyn Provider>)>,  // OWNED: wrapper owns every Box
}

impl Provider for ReliableProvider {
    async fn chat(&self, request: ChatRequest<'_>, model: &str, temp: f64) -> Result<ChatResponse> {
        // BORROW: request (and request.messages) for the whole call
        for (name, box_provider) in &self.providers {  // BORROW: iterate, no move
            match box_provider.chat(request, model, temp).await {
                Ok(r) => return Ok(r),
                Err(_) => continue,  // try next provider
            }
        }
        Err(...)
    }
}

    Request types borrow message slices; provider does not store them.

    struct ChatRequest<'a> {
    messages: &'a [ChatMessage],   // BORROW: slice lives as long as caller holds the messages
    tools: Option<&'a [ToolSpec]>,
}

// Call site: provider borrows self; request borrows messages; model/temp copied

    ChatRequest { messages: &history, tools: Some(&specs) },

    When used (borrow vs transfer)

    • create_provider(name, api_key) — name and api_key are borrowed; return value is Box (ownership transferred to caller). create_resilient_provider builds multiple providers (each create_provider returns Box), pushes into Vec<(String, Box)>, then moves that Vec into ReliableProvider::new(providers) — so ownership of all Boxes is transferred into the wrapper.
    • When caller invokes provider.chat(request, model, temp): provider is borrowed (&self). ChatRequest holds messages: &[ChatMessage] and tools: Option<&[ToolSpec]>; so the provider borrows those slices for the duration of chat(). model and temp are copied. No ownership transfer of messages.
    • ReliableProvider.chat(...) — &self borrows the wrapper; internally it gets a (name, box_provider) from self.providers (borrows from Vec), then calls box_provider.chat(...) so the inner provider is borrowed for that call. Same for RouterProvider: resolve(model) borrows &self and returns (index, model_string); then self.providers[index].1 is borrowed to call .chat(...).

    Module: tools

    Tool list: Vec> built once; tools hold Arc for shared deps.

    // SHARED: security is Arc; we clone it for each tool so they share the same policy
fn default_tools(security: Arc<SecurityPolicy>) -> Vec<Box<dyn Tool>> {

    Example tool: shared policy and runtime.

    struct ShellTool {
    security: Arc<SecurityPolicy>,   // SHARED: many tools can hold clone of same Arc
    runtime: Arc<dyn RuntimeAdapter>,
}

impl Tool for ShellTool {
    async fn execute(&self, args: serde_json::Value) -> Result<ToolResult> {
        // BORROW: &self for the call; args is moved in (or clone if needed)
        let allowed = self.security.allow_command(&cmd);  // BORROW: security and cmd
        let mut cmd = self.runtime.build_shell_command(&c, &self.workspace)?;  // BORROW
        self.security.sandbox().wrap_command(&mut cmd);   // BORROW MUT: cmd
        let output = cmd.output().await?;   // cmd consumed by output()
        Ok(ToolResult { success: true, output, error: None })  // OWNED: return to caller
    }
}

    When used (borrow vs transfer)

    Module: skills / skillforge / integrations / migration / onboard / doctor / daemon / service / util

    Skills: Skill is a loaded struct (owned). Skillforge: config and report structs owned; no trait object ownership. Integrations: status and entry structs. Migration: borrows paths, creates memory temporarily. Onboard: wizard builds ProjectContext (owned). Doctor/daemon/service: orchestration only; borrow Config, call into other modules. Util: pure functions; borrow inputs, return owned or ref as appropriate. No repeated ownership pattern beyond config borrow and owned return values.

    • load_skills(workspace_dir: &Path) — path borrowed; returns Vec (owned). Skills are built from filesystem; caller owns the Vec. Skillforge: evaluator/scout take config or refs; return ForgeReport or Vec (owned). Integrations: list/status functions borrow config; return owned vecs of entries.

Onboard: wizard takes &Config or &Path; builds ProjectContext (owned) and may modify config on disk (path borrowed). Doctor/daemon/service: entry points take Config by value or ref; they call other modules with &config or pass ownership (e.g. config to run (config)); no long-lived storage of config in these thin layers. Util: e.g. truncate_with_ellipsis(s, n) — s borrowed; returns String (owned). No shared mutable state.
