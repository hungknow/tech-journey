How to Create a New Table (React Table + Common Components)

This guide describes how to build a new table for a new data model using the shared table components and TanStack Table (React Table v8). Use it as a template when adding a new feature that needs a data table.

1. Shared Table Components (components/common/table/)

The app provides a generic table shell that works with any TanStack Table instance:

Component Role
Table Wrapper: takes a table instance, loading, error, optional emptyChildren, optional loaderRows. Renders a scrollable container, <table>, and composes Header, Footer, Body. Shows emptyChildren when there are no rows (and not loading/error); shows ErrorDisplay when error is set.
TableHeader Renders <thead> and uses flexRender for each column’s header.
TableBody Renders <tbody>: either a loading skeleton (TableBodyLoader) or rows/cells via flexRender. Note: TableBody and TableBodyLoader apply compact styling (w-0) to the column with id 'Select'. Use that id for a select column if you want that behavior, or extend these components to accept an optional “compact column id” prop.
TableFooter Renders <tfoot> only if at least one column defines a footer. Uses flexRender for each column’s footer.

Table props (generic):

interface TableProps<T> {
  loading: boolean;
  table: ReactTable<T>;
  error?: Nullable<Error>;
  emptyChildren?: React.ReactNode;
  loaderRows?: number;
  className?: string;
}

You do not implement <table>, <thead>, <tbody>, or <tfoot> yourself; you only define columns and data, then pass the table instance into <Table>.

2. Steps to Add a New Table for a New Data Model

Step 1: Define the row data type and row ID

  • Define a TypeScript type/interface for one row (e.g. MyFeatureRow).
  • Choose a stable, unique row ID (string) per row. Implement:
const getRowId = (row: MyFeatureRow) => string;

Example: (${row.chainId}-${row.contract.address}-${row.spender}-${row.tokenId}).

  • Use this in useReactTable as getRowId so selection and React keys stay correct when data changes.

Step 2: Create the column definitions

  • Create a file (e.g. components/my-feature/columns.tsx).
  • Use TanStack Table v8 and createColumnHelper<MyFeatureRow>().
  • For each column decide:
  • id — unique string (often an enum like ColumnId for type safety and reuse in initialState, filters, etc.).
  • header — optional; component or string.
  • cell — render function receiving info (e.g. info.row.original, info.getValue(), info.table.options.meta).
  • footer — optional; e.g. “Select all” or a batch action.
  • accessor — for sort/filter: use a function (row) => value or a path string. Cells can still use row.original for full data.
  • enableSorting / sortingFn / sortUndefined — if the column is sortable.
  • enableColumnFilter / filterFn — if the column is filterable.
  • enableHiding — if the column can be toggled (e.g. column visibility state).

Optional: table meta (callbacks / shared state)

  • If cells or footers need a shared callback (e.g. “onUpdate”, “onCancel”), extend TanStack’s TableMeta via declaration merging and pass the callback in meta when creating the table:
declare module '@tanstack/table-core' {
  interface TableMeta<TData extends RowData> {
    onUpdate?: (payload: ...) => void;  // or your callback type
  }
}

Then in useReactTable: meta: { onUpdate }. In cells: info.table.options.meta?.onUpdate.

Column Definition Examples

Display-only column (no accessor): 

columnHelper.display({
  id: ColumnId.ACTIONS,
  header: ...,
  cell: (info) => <ActionsCell row={info.row.original} />
});

Data column with accessor: 

columnHelper.accessor(accessors.myField, {
  id: ColumnId.MY_FIELD,
  header: ...,
  cell: (info) => <MyCell value={info.getValue()} row={info.row.original} />,
  enableSorting: true,
  sortingFn: ...,
});

Footer only column (e.g. global select): 

columnHelper.display({
  id: ColumnId.SELECT,
  footer: ({ table }) => <GlobalSelectCell table={table} />,
  cell: ...,
});

What to export from your columns file: - ColumnId enum (or const object) - columns array - Optionally: accessors and any custom sortingFn / filterFn objects

Step 3: Wire up data and table state

  • Get your data from hooks/context (e.g. React Query). Memoize the array passed to the table: const data = useMemo(() => sourceData ?? [], [sourceData]);.
  • Create the table with useReactTable:
const table = useReactTable({
  data,
  columns,
  getRowId,
  getCoreRowModel: getCoreRowModel<MyFeatureRow>(),
  getSortedRowModel: getSortedRowModel<MyFeatureRow>(),
  getFilteredRowModel: getFilteredRowModel<MyFeatureRow>(),
  state: {
    rowSelection,        // if you need selection
    sorting,             // if you want controlled sort
    columnFilters,
    columnVisibility,
  },
  onRowSelectionChange: setRowSelection,
  enableRowSelection: (row) => ... ,  // optional
  meta: { onUpdate },    // optional
  initialState: {
    sorting: [{ id: ColumnId.SOME_COL, desc: true }],
    columnVisibility: { [ColumnId.HIDDEN_BY_DEFAULT]: false },
  },
});
  • If you use row selection and the list can change (e.g. rows removed), sync selection when data changes in a useEffect: keep only selected IDs that still exist in the current data.

Step 4: Render the table and optional controls

  • Import Table from components/common/table/Table.
  • Render:
  • Any controls above the table (sort, filter, search) that read/write table state (e.g. table.getState(), table.setSorting(), table.setColumnFilters()).
  • Table with:
    • table={table}
    • loading={isLoading} and error={error} from your data layer
    • emptyChildren={<YourEmptyMessage />} when there are no rows
    • loaderRows={n} optional
    • className optional

Example:

return (
  <div className="flex flex-col gap-2">
    <MyTableControls table={table} />
    <Table
      table={table}
      loading={isLoading}
      error={error}
      emptyChildren={<NoItemsFound />}
      loaderRows={10}
    />
  </div>
);

Step 5: Cell and footer components

Implement one component per cell type; pass into the column’s cell (and optionally header / footer) the props they need. See §3 Defining cell components for how to define and wire them.

3. Defining cell components

Cell components are normal React components. You decide what props they receive; the column definition pulls those values from the cell context that TanStack Table passes to the cell render function.

What the column cell function receives

The cell property is a function that receives one argument — the cell context (TanStack’s CellContext<MyFeatureRow>). It has at least:

Property Type Use
row Row<MyFeatureRow> The table row. row.original is your row data. For selection: row.getCanSelect(), row.getIsSelected(), row.getToggleSelectedHandler().
getValue() () => unknown Value from this column’s accessor (what sorting/filtering use). Only available when the column has an accessor.
table Table<MyFeatureRow> The table instance. Use table.options.meta for shared callbacks (e.g. onUpdate).
column Column<MyFeatureRow, unknown> Column definition (e.g. column.id).

You never pass the whole context into your component. You pass only the props the component needs.

Defining a body cell component

  1. Create a component that accepts only the props it needs (row data, accessor value, row object for selection, or meta callbacks).
  2. In the column definition, call that component from cell and pass those props from the context.

Pattern A — Row data only

Use when the cell only needs the row’s data. Good for display or when the cell does not need the accessor value or selection.

// MyCell.tsx
interface Props {
  item: MyFeatureRow;
}

const MyCell = ({ item }: Props) => {
  return <div>{item.name}</div>;
};

export default MyCell;

// columns.tsx
cell: (info) => <MyCell item={info.row.original} />

Pattern B — Accessor value only

Use when the cell only needs the value used for sorting/filtering (e.g. a label or a simple derived value). Keeps the cell simple and aligned with the accessor.

// TypeCell.tsx
interface Props {
  type: 'NFT' | 'Token';  // type matches your accessor return type
}

const TypeCell = ({ type }: Props) => {
  return <Label>{type}</Label>;
};

export default TypeCell;

// columns.tsx — column has an accessor that returns 'NFT' | 'Token'
cell: (info) => <TypeCell type={info.getValue() as 'NFT' | 'Token'} />
// or with a type-safe accessor: getValue() is already the right type
cell: (info) => <TypeCell type={info.getValue()} />

Pattern C — Row data + meta callback

Use when the cell needs both the row and a shared callback from table meta (e.g. refresh after an action).

// ActionsCell.tsx
interface Props {
  item: MyFeatureRow;
  onUpdate: (id: string) => void;
}

const ActionsCell = ({ item, onUpdate }: Props) => {
  return (
    <button type="button" onClick={() => onUpdate(item.id)}>
      Update
    </button>
  );
};

export default ActionsCell;

// columns.tsx — TableMeta extended with onUpdate
cell: (info) => (
  <ActionsCell
    item={info.row.original}
    onUpdate={info.table.options.meta!.onUpdate!}
  />
)

Pattern D — Full row (selection cell)

Use for a checkbox or other selection UI. The component needs the TanStack Row object to call selection APIs.

// SelectCell.tsx
import type { Row } from '@tanstack/react-table';

interface Props {
  row: Row<MyFeatureRow>;
}

const SelectCell = ({ row }: Props) => {
  if (!row.getCanSelect()) return null;
  return (
    <Checkbox
      checked={row.getIsSelected()}
      onChange={row.getToggleSelectedHandler()}
    />
  );
};

export default SelectCell;

// columns.tsx
cell: ({ row }) => <SelectCell row={row} />

Defining a header component

Headers are rendered by the column’s header. They usually don’t receive row data — only static props like label or i18n key.

// HeaderCell.tsx
interface Props {
  i18nKey: string;
  align?: 'left' | 'right';
}

const HeaderCell = ({ i18nKey, align }: Props) => {
  const t = useTranslations();
  return <div className={align === 'right' ? 'text-right' : ''}>{t(i18nKey)}</div>;
};

export default HeaderCell;

// columns.tsx
header: () => <HeaderCell i18nKey="myFeature.headers.name" />

Defining a footer component

Footer components are used for “select all” or batch actions. The column’s footer receives the table instance (and optionally header context). Your component receives table and uses table APIs.

// GlobalSelectCell.tsx
import type { Table } from '@tanstack/react-table';

interface Props {
  table: Table<MyFeatureRow>;
}

const GlobalSelectCell = ({ table }: Props) => {
  const selectableRows = table.getRowModel().flatRows.filter((row) => row.getCanSelect());
  const allSelected = selectableRows.length > 0 && table.getSelectedRowModel().flatRows.length === selectableRows.length;
  return (
    <Checkbox
      checked={allSelected}
      indeterminate={table.getSelectedRowModel().flatRows.length > 0 && !allSelected}
      onChange={table.getToggleAllRowsSelectedHandler()}
    />
  );
};

export default GlobalSelectCell;

// columns.tsx
footer: ({ table }) => <GlobalSelectCell table={table} />

Typing summary

  • Row data: info.row.original is typed as your row type (e.g. MyFeatureRow) when you use createColumnHelper<MyFeatureRow>() and useReactTable with that type.
  • Row object: Type as Row<MyFeatureRow> from @tanstack/react-table.
  • Table (footer): Type as Table<MyFeatureRow>.
  • Meta: After extending TableMeta via module augmentation, info.table.options.meta is typed with your fields (e.g. onUpdate).

4. Checklist for a New Table

  • [ ] Row type and stable getRowId defined.
  • [ ] columns.tsx with createColumnHelper<RowType>(), column ids, accessors, and optional meta types.
  • [ ] Optional: TableMeta extended and meta passed into useReactTable.
  • [ ] Table state: getCoreRowModel, getSortedRowModel, getFilteredRowModel; optional state/onRowSelectionChange/enableRowSelection.
  • [ ] If using selection and data can change: sync rowSelection with current data (e.g. in useEffect).
  • [ ] Data memoized and passed as data; loading/error from data layer passed to <Table>.
  • [ ] <Table> used with table, loading, error, emptyChildren; optional loaderRows, className.
  • [ ] Optional: controls component that uses table for sort/filter/search.
  • [ ] If you need the compact “select” column styling: use column id 'Select' or extend TableBody/TableBodyLoader to accept a configurable column id.

6. Code sample: comprehensive table (varying types)

Minimal end-to-end example with row data that includes boolean, text, number, and enum fields. Code is compact but runnable.

Row type and data

// types.ts or inline
type Status = 'pending' | 'approved' | 'rejected';

interface SampleRow {
  id: string;
  name: string;           // text
  count: number;
  active: boolean;
  status: Status;         // enum
}

const SAMPLE_DATA: SampleRow[] = [
  { id: '1', name: 'Alpha', count: 10, active: true, status: 'approved' },
  { id: '2', name: 'Beta', count: 0, active: false, status: 'pending' },
  { id: '3', name: 'Gamma', count: 3, active: true, status: 'rejected' },
];

Columns and accessors

// columns.tsx
import { createColumnHelper, filterFns, type Row, type RowData, sortingFns } from '@tanstack/react-table';
import type { SampleRow, Status } from './types';

declare module '@tanstack/table-core' {
  interface TableMeta<TData extends RowData> {
    onStatusChange?: (id: string, status: Status) => void;
  }
}

const columnHelper = createColumnHelper<SampleRow>();
const STATUS_OPTIONS: Status[] = ['pending', 'approved', 'rejected'];

export enum ColumnId {
  SELECT = 'Select',
  NAME = 'Name',
  COUNT = 'Count',
  ACTIVE = 'Active',
  STATUS = 'Status',
  ACTIONS = 'Actions',
}

const accessors = {
  name: (r: SampleRow) => r.name,
  count: (r: SampleRow) => r.count,
  active: (r: SampleRow) => r.active,
  status: (r: SampleRow) => r.status,
};

const statusFilterFn = (row: Row<SampleRow>, _: string, filterValues: Status[]) =>
  filterValues.includes(row.getValue(ColumnId.STATUS) as Status);

export const columns = [
  columnHelper.display({
    id: ColumnId.SELECT,
    cell: ({ row }) => (
      <input
        type="checkbox"
        checked={row.getIsSelected()}
        disabled={!row.getCanSelect()}
        onChange={row.getToggleSelectedHandler()}
      />
    ),
  }),
  columnHelper.accessor(accessors.name, {
    id: ColumnId.NAME,
    header: 'Name',
    cell: (info) => <span>{info.getValue()}</span>,
    enableSorting: true,
    sortingFn: sortingFns.text,
    enableColumnFilter: true,
    filterFn: filterFns.includesString,
  }),
  columnHelper.accessor(accessors.count, {
    id: ColumnId.COUNT,
    header: 'Count',
    cell: (info) => <span>{info.getValue()}</span>,
    enableSorting: true,
    sortingFn: sortingFns.basic,
  }),
  columnHelper.accessor(accessors.active, {
    id: ColumnId.ACTIVE,
    header: 'Active',
    cell: (info) => <span>{info.getValue() ? 'Yes' : 'No'}</span>,
    enableSorting: true,
    sortingFn: (a, b, id) => (a.getValue(id) === b.getValue(id) ? 0 : a.getValue(id) ? 1 : -1),
    enableColumnFilter: true,
    filterFn: (row, _, value: boolean[]) => value.includes(row.getValue(ColumnId.ACTIVE)),
  }),
  columnHelper.accessor(accessors.status, {
    id: ColumnId.STATUS,
    header: 'Status',
    cell: (info) => (
      <select
        value={info.getValue()}
        onChange={(e) => info.table.options.meta?.onStatusChange?.(info.row.original.id, e.target.value as Status)}
      >
        {STATUS_OPTIONS.map((s) => (
          <option key={s} value={s}>{s}</option>
        ))}
      </select>
    ),
    enableSorting: true,
    sortingFn: sortingFns.text,
    enableColumnFilter: true,
    filterFn: statusFilterFn,
  }),
  columnHelper.display({
    id: ColumnId.ACTIONS,
    header: 'Actions',
    cell: (info) => <button type="button">Edit {info.row.original.id}</button>,
  }),
];

Table component

// SampleTable.tsx
import { getCoreRowModel, getFilteredRowModel, getSortedRowModel, useReactTable } from '@tanstack/react-table';
import Table from 'components/common/table/Table';
import { useCallback, useMemo, useState } from 'react';
import type { SampleRow, Status } from './types';
import { SAMPLE_DATA } from './types';
import { ColumnId, columns } from './columns';

const getRowId = (row: SampleRow) => row.id;

export const SampleTable = () => {
  const [rowSelection, setRowSelection] = useState<Record<string, boolean>>({});
  const [data, setData] = useState<SampleRow[]>(() => SAMPLE_DATA);

  const onStatusChange = useCallback((id: string, status: Status) => {
    setData((prev) => prev.map((row) => (row.id === id ? { ...row, status } : row)));
  }, []);

  const table = useReactTable({
    data,
    columns,
    getRowId,
    state: { rowSelection },
    onRowSelectionChange: setRowSelection,
    enableRowSelection: true,
    getCoreRowModel: getCoreRowModel<SampleRow>(),
    getSortedRowModel: getSortedRowModel<SampleRow>(),
    getFilteredRowModel: getFilteredRowModel<SampleRow>(),
    initialState: { sorting: [{ id: ColumnId.NAME, desc: false }] },
    meta: { onStatusChange },
  });

  return (
    <Table
      table={table}
      loading={false}
      emptyChildren={<p>No rows</p>}
    />
  );
};
