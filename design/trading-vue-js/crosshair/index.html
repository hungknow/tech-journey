Crosshair Component

Overview

The Crosshair component displays a crosshair overlay that follows cursor movement across the trading chart grid. It consists of a Vue wrapper (Crosshair.vue) and a renderer class (crosshair.js).

Models

Component State

  • ch (Crosshair): Instance of the Crosshair renderer class

Crosshair Renderer State

  • comp (Object): Reference to the Vue component
  • $p (Object): Alias for component props
  • data (Object): Alias for this.$p.sub (subscription data)
  • _visible (Boolean): Internal visibility state
  • locked (Boolean): Whether the crosshair is locked
  • layout (Object): Grid layout reference
  • x (Number): Current crosshair X position
  • y (Number): Current crosshair Y position

API

Vue Component Props

Prop Type Description
cursor Object Cursor object containing position (x, y), mode, and grid_id
colors Object Color configuration; colors.cross defines crosshair color
layout Object Grid layout with id, width, height
sub Object Subscription data

Vue Component Methods

  • create(): Initializes the Crosshair instance and registers it as a grid renderer

Vue Component Events Emitted

  • new-grid-layer: Registers the crosshair as a grid overlay renderer
  • redraw-grid: Requests a grid redraw

Crosshair Renderer Methods

Method Parameters Description
draw(ctx) ctx (CanvasRenderingContext2D) Renders the crosshair lines on the canvas
hide() - Hides the crosshair and resets position
get visible() - Returns the current visibility state
set visible(val) val (Boolean) Sets the visibility state

Model Calculation and Construction

Initialization

  1. Vue component mounts and watches cursor prop
  2. On first cursor update, create() is called:
  3. Instantiates Crosshair class with component reference
  4. Emits new-grid-layer event with renderer descriptor
  5. Grid system calls the renderer's draw() method on each frame

Visibility Logic

Crosshair is hidden when: - Cursor x or y is undefined - Cursor mode is 'explore' (default mobile mode)

this.ch.visible = !explore

Draw Method Execution

draw(ctx) performs the following:

  1. Updates layout reference from current props
  2. Checks visibility state; returns early if invisible and in explore mode
  3. Retrieves cursor position from props
  4. Saves canvas context
  5. Sets stroke color to this.$p.colors.cross
  6. Begins path with dashed line pattern [5]
  7. Horizontal Line (H): Drawn only when cursor.grid_id === layout.id
  8. Spans from left edge (x=0) to right edge (x=layout.width - 0.5) at cursor's Y position
  9. Vertical Line (V): Always drawn
  10. Spans from top (y=0) to bottom (y=layout.height) at cursor's X position
  11. Strokes the path and restores context

Coordinate System

  • X coordinate: Pixel position within the grid width
  • Y coordinate: Pixel position within the grid height
  • Grid boundaries: Defined by layout.width and layout.height
  • Multi-grid support: Horizontal line only appears on the grid where cursor originated (checked via grid_id)

Hide Method

Sets _visible to false and resets x and y to undefined.
