Chart Layout System

Overview

The chart layout system calculates all dimensions, positions, and coordinate transformations required to render the trading chart. It determines where to draw the legend, axes, overlays, and chart elements based on the available space and data.

Core Concepts

Layout Object

The layout is calculated by the Layout() function in src/components/js/layout.js, which returns an object containing:

{
    grids: [...],      // Array of grid objects (main + offchart)
    botbar: {          // Bottom bar dimensions
        width, height, offset, xs
    }
}

Predefined Dimensions

The chart uses predefined dimensions from src/stuff/constants.js:

const ChartConfig = {
    SBMIN: 60,       // Minimal sidebar width (px)
    SBMAX: Infinity, // Max sidebar width (px)
    TOOLBAR: 57,     // Toolbar width (px)
    TB_ICON: 25,     // Toolbar icon size (px)
    CANDLEW: 0.6,    // Candle width as % of step
    GRIDX: 100,      // Target X-axis grid spacing (px)
    GRIDY: 47,       // Target Y-axis grid spacing (px)
    BOTBAR: 28,      // Bottom bar height (px)
    PANHEIGHT: 22,   // Cursor info panel height (px)
    VOLSCALE: 0.15,  // Volume scale as % of height
    EXPAND: 0.15     // % of range to expand for padding
}

Layout Structure

Vertical Organization

The chart is divided vertically into three main sections:

┌─────────────────────────────────────┐
│         Legend (overlay)            │  <- Positioned at top
├─────────────────────────────────────┤
│                                     │
│         Grid Area                   │
│      (Main Chart + Offchart)        │
│                                     │
├─────────────────────────────────────┤
│         Botbar                      │  <- Time axis
└─────────────────────────────────────┘

Horizontal Organization (Grid Section)

Each grid section consists of:

┌────────────────────┬────────┐
│                    │        │
│      Grid          │Sidebar │
│   (Main Chart)     │(Y-axis)│
│                    │        │
└────────────────────┴────────┘
     width = total - sb    sb

Grid Layout Calculation

Height Distribution

Grid heights are calculated in grid_hs() function (layout.js:30-50):

Method 1: Weighted Heights If any grid has a defined height value: - Calculate weights from all grid heights (default = 1) - Distribute total height proportionally - Use floor() and distribute remaining pixels evenly

Method 2: Automatic Distribution If no heights defined: - Main chart gets: height - offchart_height * n - Offchart each gets: height * (2 * sqrt(n) / 7) / n - Where n = number of offchart indicators

Grid Object Structure

Each grid object contains:

{
    id: 0,                    // Grid index
    width: number,            // Grid width (excludes sidebar)
    height: number,           // Grid height
    sb: number,               // Sidebar width
    offset: number,           // Vertical offset from top
    spacex: number,           // Available X space (width)
    startx: number,           // Starting X position
    px_step: number,          // Pixels per candle interval
    A: number,                // Y-axis scale factor
    B: number,                // Y-axis shift factor
    $_hi: number,             // Y-axis high value
    $_lo: number,             // Y-axis low value
    $_step: number,           // Y-axis grid step
    t_step: number,           // Time axis grid step
    xs: [[x, data, rank], ...], // X-axis grid positions
    ys: [[y, value], ...],   // Y-axis grid positions
    candles: [...],          // Candlestick positions
    volume: [...],            // Volume bar positions
    grid: {...},              // Grid configuration
    master_grid: ref,         // Reference to main grid (for offchart)
    ti_map: {...},            // Time index mapping
    // Coordinate transformation functions:
    t2screen(t),              // Timestamp -> screen X
    $2screen(y),              // Price -> screen Y
    screen2t(x),              // Screen X -> timestamp
    screen2$(y),              // Screen Y -> price
    t_magnet(t),              // Nearest time grid line
    c_magnet(t)               // Nearest candle
}

Sidebar Layout

Width Calculation

Sidebar width is calculated in calc_sidebar() (grid_maker.js:87-114):

  1. Calculate precision needed based on data range
  2. Format high and low values with that precision
  3. Measure text width with padding (4 spaces)
  4. Clamp between SBMIN and SBMAX
// Example calculation
prec = 4              // Decimal places
sb = ctx.measureText("1234.5678    ").width  // ~80px
sb = Math.max(sb, SBMIN)  // Ensure minimum
sb = Math.min(sb, SBMAX)  // Ensure maximum

Positioning

Sidebar is positioned at: - X: grid.width (right edge of grid) - Y: grid.offset (vertical offset) - Width: grid.sb - Height: grid.height

Legend Layout

Positioning

Legend is positioned at (Legend.vue:110-116):

calc_style() {
    let top = grid.height > 150 ? 10 : 5
    return {
        top: `${grid.offset + top}px`,
        width: `${grid.width - 20}px`
    }
}
  • X: 10px from left edge
  • Y: offset + 10px (or 5px if height < 150)
  • Width: Grid width - 20px

Content

  • Main chart grid shows: OHLCV values, title
  • Offchart grids show: Indicator names, values
  • Values only shown when cursor mode !== 'explore'

Botbar Layout

Dimensions

{
    width: total_width,
    height: BOTBAR (28px),
    offset: sum of all grid heights,
    xs: [...]  // Time grid positions (from main grid)
}

Time Labels

Time labels are drawn from the main grid's xs array: - Each element: [x_position, [timestamp], rank] - Rank determines highlight level (YEAR, MONTH, DAY, etc.) - Labels are clipped at sidebar position

Coordinate Transformations

Y-Axis (Price) Transformation

Linear scale: 

A = -height / ($hi - $lo)     // Scale factor
B = -$hi * A                  // Shift factor
$2screen(y) = y * A + B       // Price -> pixel
screen2$(y) = (y - B) / A     // Pixel -> price

Logarithmic scale: 

A = -height / (log($hi) - log($lo))
B = -log($hi) * A
$2screen(y) = log(y) * A + B
screen2$(y) = exp((y - B) / A)

X-Axis (Time) Transformation

spacex = width - sb                              // Available space
dt = range[1] - range[0]                         // Time range
r = spacex / dt                                  // Ratio
px_step = spacex / (dt / interval)               // Pixels per candle
t2screen(t) = (t - range[0]) * r                // Timestamp -> pixel
screen2t(x) = range[0] + x / r                   // Pixel -> timestamp

Grid Line Calculation

X-Axis (Time) Grid

Time grid lines are calculated in grid_x() (grid_maker.js:258-315):

  1. Select appropriate time step from TIMESCALES
  2. Insert lines at year/month/day boundaries
  3. Filter lines too close together (less than 80% of step)
  4. Extend grid left/right for smaller timeframes

Time steps available: - Years: 10, 5, 3, 2, 1 - Months: 6, 4, 3, 2, 1 - Days: 15, 10, 7, 5, 3, 2, 1 - Hours: 12, 6, 3, 1.5, 1 - Minutes: 30, 15, 10, 5, 2, 1

Y-Axis (Price) Grid

Price grid lines are calculated in grid_y() (grid_maker.js:378-393):

  1. Calculate step from $SCALES based on y-range
  2. Start from first aligned value: $lo - ($lo % step)
  3. Generate grid lines until $hi

For logarithmic scale (grid_y_log()): - Use multiplicative steps instead of additive - Calculate different multipliers for positive and negative ranges - Round values to nice numbers

Candlestick Layout

Candlestick positions are calculated in candles_n_vol() (layout.js:63-103):

for each candle:
    mid = t2screen(timestamp) + 0.5    // Center X position
    x = mid                           // X position
    w = px_step * CANDLEW             // Width (60% of step)
    o = floor(open * A + B)           // Open Y
    h = floor(high * A + B)           // High Y
    l = floor(low * A + B)            // Low Y
    c = floor(close * A + B)          // Close Y

Volume bars are aligned with candlesticks: - Width covers full candle area with small gaps - Height scaled by VOLSCALE * height / max_volume - Green color if close >= open, red otherwise

Offchart Grids

Offchart indicator grids: - Share X-axis with main grid (same xs, px_step, startx) - Have independent Y-axis (own $_hi, $_lo, ys) - Reference main grid via master_grid - Can merge with existing grids using grid.id

Layout Update Flow

When chart needs to recalculate layout:

  1. Chart.vue calls update_layout()
  2. Layout() creates new layout object
  3. GridMaker creates each grid with proper dimensions
  4. Utils.copy_layout() updates existing layout in place
  5. Components receive new layout via props
  6. Canvas renderers redraw with new coordinates

Layout is recalculated on: - Width/height changes - Range changes - Data updates - Sidebar transform changes - Grid configuration changes

Component Hierarchy

Chart.vue
├── GridSection (for each grid)
│   ├── Legend (overlay)
│   ├── Grid
│   │   ├── Canvas
│   │   ├── Crosshair
│   │   └── Overlays (Candles, Indicators, etc.)
│   └── Sidebar
└── Botbar

Each component uses the layout object to position itself:

// Grid.vue (line 74-82)
position: {
    x: 0,
    y: layout.offset
}
attrs: {
    width: layout.width,
    height: layout.height
}

// Sidebar.vue (line 24-28)
position: {
    x: layout.width,
    y: layout.offset
}
attrs: {
    width: grid.sb,
    height: layout.height
}

// Botbar.vue (line 24-27)
position: {
    x: 0,
    y: botbar.offset
}
attrs: {
    width: botbar.width,
    height: botbar.height
}

Summary

The chart layout system:

  1. Calculates dimensions based on total size and configuration
  2. Distributes space between main chart and offchart indicators
  3. Determines positions for all chart elements (legend, axes, overlays)
  4. Computes transformations between data coordinates and screen coordinates
  5. Generates grid lines at appropriate intervals for both axes
  6. Positions candlesticks and other visual elements using coordinate transforms

All layout calculations happen in Layout() and GridMaker, creating a consistent coordinate system used throughout the chart for positioning and rendering.
