Chart Drawing Timing and Order

This document describes how TradingVue.js renders chart elements, including the execution timing and rendering order.

Component Hierarchy

TradingVue.vue (root)
└── Chart.vue
    ├── GridSection.vue (for each grid)
    │   ├── Grid.vue (canvas-based)
    │   ├── Sidebar.vue (canvas-based)
    │   └── Legend.vue (HTML-based)
    └── Botbar.vue (canvas-based)

Rendering Phases

1. Initialization Phase

Chart.vue (created() hook - src/components/Chart.vue:54-69): 

created() {
    // 1. Create Context for text measurements
    this.ctx = new Context(this.$props)

    // 2. Calculate initial time range
    this.init_range()          // Determines visible time window

    // 3. Subset the data for current range
    this.sub = this.subset()  // Filters data for visible area

    // 4. Create layout with all measurements
    this._layout = new Layout(this)  // Calculates positions, scales

    // 5. Initialize cursor value updater
    this.updater = new CursorUpdater(this)

    // 6. Initialize shaders
    this.init_shaders(this.skin)
}

Layout Calculation (src/components/js/layout.js): - grid_hs() - Splits vertical space between main and offchart grids - GridMaker - For each grid: - calc_$range() - Calculates Y-axis price range - calc_sidebar() - Calculates sidebar width based on precision - calc_positions() - Calculates pixel positions and transforms - grid_x() - Calculates vertical grid line positions - grid_y() / grid_y_log() - Calculates horizontal grid line positions

2. Canvas Setup Phase

Grid.vue (mounted() hook - src/components/Grid.vue:63-67): 

mounted() {
    const el = this.$refs['canvas']
    this.renderer = new Grid(el, this)  // Create renderer
    this.setup()                        // Canvas mixin setup
    this.$nextTick(() => this.redraw()) // Initial draw
}

Canvas Setup (src/mixins/canvas.js:8-35): 

setup() {
    const canvas = document.getElementById(id)
    let dpr = window.devicePixelRatio || 1  // Handle Retina displays

    // Set CSS size
    canvas.style.width = `${this._attrs.width}px`
    canvas.style.height = `${this._attrs.height}px`

    // Set actual canvas size (scaled by DPR)
    canvas.width = rect.width * dpr
    canvas.height = rect.height * dpr

    // Create 2D context and apply DPR scaling
    const ctx = canvas.getContext('2d')
    ctx.scale(dpr, dpr)

    // Measure text helper
    ctx.measureText = text => Utils.measureText(ctx, text, tv_id)

    this.redraw()  // Trigger first draw
}

Sidebar.vue and Botbar.vue follow the same pattern with their respective renderers.

3. Main Drawing Loop

Grid.update() (src/components/js/grid.js:274-306):

update() {
    // 1. Update references
    this.layout = this.$p.layout.grids[this.id]
    this.interval = this.$p.interval

    // 2. Clear the entire canvas
    this.ctx.clearRect(0, 0, this.canvas.width, this.canvas.height)

    // 3. Apply shaders (custom rendering before grid)
    if (this.$p.shaders.length) this.apply_shaders()

    // 4. Draw the grid lines
    this.grid()

    // 5. Sort overlays by z-index
    let overlays = [...this.overlays]
    overlays.sort((l1, l2) => l1.z - l2.z)

    // 6. Draw each overlay layer
    overlays.forEach(l => {
        if (!l.display) return  // Skip hidden layers
        this.ctx.save()
        let r = l.renderer
        if (r.pre_draw) r.pre_draw(this.ctx)  // Optional pre-draw
        r.draw(this.ctx)                      // Main draw
        if (r.post_draw) r.post_draw(this.ctx) // Optional post-draw
        this.ctx.restore()
    })

    // 7. Draw crosshair (always on top)
    if (this.crosshair) {
        this.crosshair.renderer.draw(this.ctx)
    }
}

4. Drawing Order Details

Layer 1: Shaders (Optional)

  • Custom rendering functions that can draw before anything else
  • Applied with ctx.save() / ctx.restore() for isolation
  • Target: grid, sidebar, or botbar

Layer 2: Grid Lines

  • Vertical grid lines at time intervals
  • Horizontal grid lines at price levels
  • Grid border (top line for each grid)

Layer 3: Overlays (Sorted by z-index)

Default z-index values: - Main chart overlays: 0 - Offchart/indicator overlays: -1 - Custom overlays: specified in settings

Candles Overlay (src/components/overlays/Candles.vue:21-48): 

draw(ctx) {
    // 1. Draw volume bars (if enabled)
    if (this.show_volume) {
        for (var i = 0, n = cv.length; i < n; i++) {
            new Volbar(this, ctx, cv[i])
        }
    }

    // 2. Draw candlesticks
    for (var i = 0, n = cc.length; i < n; i++) {
        new Candle(this, ctx, cc[i])
    }

    // 3. Draw current price line (if enabled)
    if (this.price_line) this.price.draw(ctx)
}

Spline Overlay (src/components/overlays/Spline.vue:34-66): 

draw(ctx) {
    ctx.lineWidth = this.line_width
    ctx.strokeStyle = this.color
    ctx.beginPath()

    // Draw connected line segments
    for (var k = 0, n = data.length; k < n; k++) {
        let p = data[k]
        let x = layout.t2screen(p[0])
        let y = layout.$2screen(p[i])
        ctx.lineTo(x, y)
    }
    ctx.stroke()
}

Other overlays (Range, Segment, Channel, Splines, etc.) follow the same pattern.

Layer 4: Crosshair

  • Horizontal and vertical lines at cursor position
  • Dashed line style
  • Only drawn when cursor is visible and not in "explore" mode
  • Always on top of overlays

5. Sidebar Drawing

Sidebar.update() (src/components/js/sidebar.js:95-169):

update() {
    // 1. Clear and draw background
    this.ctx.clearRect(x, y, w, h)

    // 2. Draw vertical separator line
    this.ctx.strokeStyle = this.$p.colors.scale
    this.ctx.moveTo(x + 0.5, 0)
    this.ctx.lineTo(x + 0.5, h)
    this.ctx.stroke()

    // 3. Draw price labels
    for (var p of points) {
        this.ctx.moveTo(x1, p[0] - 0.5)
        this.ctx.lineTo(x2, p[0] - 0.5)
        this.ctx.fillText(p[1].toFixed(d), x1 + offst, p[0] + 4)
    }

    // 4. Draw upper border
    this.upper_border()

    // 5. Apply shaders (if any)
    this.apply_shaders()

    // 6. Draw current price panel (if cursor active)
    if (this.$p.cursor.y && this.$p.cursor.y$) this.panel()
}

6. Botbar Drawing

Botbar.update() (src/components/js/botbar.js:21-68):

update() {
    // 1. Clear and draw background
    this.ctx.clearRect(0, 0, width, height)

    // 2. Draw horizontal separator line
    this.ctx.strokeStyle = this.$p.colors.scale
    this.ctx.moveTo(0, 0.5)
    this.ctx.lineTo(Math.floor(width + 1), 0.5)
    this.ctx.stroke()

    // 3. Draw time labels
    for (var p of this.layout.botbar.xs) {
        this.ctx.moveTo(p[0] - 0.5, 0)
        this.ctx.lineTo(p[0] - 0.5, 4.5)
        this.ctx.fillText(lbl, p[0], 18)
    }

    // 4. Apply shaders (if any)
    this.apply_shaders()

    // 5. Draw cursor time panel (if cursor active)
    if (this.$p.cursor.x && this.$p.cursor.t !== undefined) this.panel()
}

7. Legend Rendering (HTML-based)

Legend components (src/components/Legend.vue) are rendered as HTML overlays using Vue's virtual DOM, positioned absolutely over the canvas. They update reactively based on cursor position.

Reactive Updates

Watchers Triggering Redraws

Grid.vue (src/components/Grid.vue:206-246): 

watch: {
    range: {
        handler: function() {
            this.$nextTick(() => this.redraw())  // Delayed redraw
        },
        deep: true
    },
    cursor: {
        handler: function() {
            if (!this.$props.cursor.locked) this.redraw()
        },
        deep: true
    },
    shaders(n, p) {
        this.redraw()  // Redraw on shader list change
    }
}

Sidebar.vue and Botbar.vue have similar watchers.

Event Flow

  1. Mouse Move:

    • Grid.mousemove() → emits 'cursor-changed' → cursor watcher → redraw()

  2. Pan/Scroll:

    • Grid.mousedrag() → updates range → range watcher → redraw()

  3. Zoom:

    • Grid.mousezoom() → updates range → range watcher → redraw()

  4. Data Update:

    • Chart.data watcher → update_layout() → range change → redraw()

Timing Considerations

DPR Scaling

  • Canvas size is multiplied by devicePixelRatio for sharp rendering on high-DPI displays
  • All drawing operations are automatically scaled via ctx.scale(dpr, dpr)

NextTick Delays

  • Initial redraw is wrapped in $nextTick() to ensure DOM is ready
  • Range changes use $nextTick() before redraw to address left-side rendering lag

Layout Recalculation

  • Layout is recalculated when:
  • Width/height changes
  • Range changes
  • Data changes
  • Y-transform (zoom/shift) changes
  • Timezone changes

Performance Optimizations

  1. Grid Rendering:

    • Uses ctx.save() / ctx.restore() for layer isolation
    • Overlays sorted once per update, not per frame
    • Hidden overlays skipped without drawing

  2. Cursor Updates:

    • Cursor locked state prevents redundant redraws
    • CursorUpdater calculates all cursor values in one pass

  3. Layout Caching:

    • Layout recalculated only when dependencies change
    • GridMaker stores intermediate calculations

Overlay Registration

Overlays register themselves when mounted (src/mixins/overlay.js:36-58):

mounted() {
    // Emit 'new-grid-layer' event
    this._$emit('new-grid-layer', {
        name: this.$options.name,
        id: this.$props.id,
        renderer: this,  // The overlay itself implements draw()
        display: display in settings ? settings.display : true,
        z: settings['z-index'] || settings['zIndex'] || (main ? 0 : -1)
    })

    // Also emit layer metadata for legend/y-range
    this._$emit('layer-meta-props', {
        grid_id: this.$props.grid_id,
        layer_id: this.$props.id,
        legend: this.legend,
        data_colors: this.data_colors,
        y_range: this.y_range
    })
}

The Grid renderer collects these layers and stores them in this.overlays array.

Complete Drawing Sequence (One Frame)

1. User interaction or data change
2. Watcher detects change
3. $nextTick() callback executes
4. Grid.update() called:
   ├─ Clear canvas
   ├─ Apply shaders (if any)
   ├─ Draw grid lines
   ├─ Draw overlays (sorted by z-index)
   │  ├─ For each overlay:
   │  │  ├─ ctx.save()
   │  │  ├─ pre_draw() (if exists)
   │  │  ├─ draw()
   │  │  ├─ post_draw() (if exists)
   │  │  └─ ctx.restore()
   └─ Draw crosshair (if visible)
5. Sidebar.update() called:
   ├─ Clear canvas
   ├─ Draw separator line
   ├─ Draw price labels
   ├─ Apply shaders (if any)
   └─ Draw cursor panel (if active)
6. Botbar.update() called:
   ├─ Clear canvas
   ├─ Draw separator line
   ├─ Draw time labels
   ├─ Apply shaders (if any)
   └─ Draw cursor panel (if active)
7. Legend updates via Vue reactivity (HTML overlay)
